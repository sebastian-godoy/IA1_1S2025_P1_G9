## Introducción 
El presente documento describe el funcionamiento de la aplicación **UniMatch**, la cual consiste en un software  avanzado para evaluar el perfil del estudiante y, con base en criterios predefinidos, recomendará las facultades y carreras que mejor se ajusten a sus características personales. Además, les ayudará también a poder definir el horario que se ajuste mejor según los cursos que deban cursar.


## Requisitos del sistema 
Para un correcto funcionamiento de la aplicación se recomiendan las siguientes especificaciónes:

| Requisito | Especificación |
|----------|----------------|
| Sistema Operativo | Windows 10/11, macOS 12+, Linux |
| Memoria RAM | Minimo 4 GB (Recomendado 8 GB) |
| Espacio en Disco | 10 GB libres |
| Procesador | Minimo Intel Core i3  |


## Instalación 
El sistema se ejecuta en el navegador por lo que no debe realizar ninguna instalación del software. Para su ejecución es necesario tener un navegador instalado en su computadora.
Para acceder al software dirigirse a la dirección:
- Acceder a `http://localhost:5500`
